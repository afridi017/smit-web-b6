Introduction to HTML Structure

Basic page structure, headings aur content organization.

What is HTML?

HTML ka full form HyperText Markup Language hai. Ye web page ka structure banane ke liye use hoti hai.

HTML content ko tags ke through organize karti hai, jaise: heading, paragraph, image, table aur form.

Basic HTML Page Flow

Har HTML file me usually ye cheezein hoti hain:

  1. DOCTYPE — browser ko version batata hai
  2. html — root element
  3. head — metadata, title, style
  4. body — visible content
