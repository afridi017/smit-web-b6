Important Flexbox Points:

  • display: flex = Parent pe lagta hai
  • justify-content = X-Axis alignment jab `flex-direction: row` ho
  • align-items = Y-Axis alignment single line ke liye
  • align-content = Y-Axis alignment multiple lines ke liye jab `flex-wrap: wrap` ho
  • gap = Boxes ke darmiyan space
  • flex-wrap: wrap = Items ko neeche bhej deta hai agar jagah kam ho
