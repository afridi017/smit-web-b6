❌ Problem

Do alag transform likhne se sirf last wala apply hota hai. Isi liye scale gayab ho jata hai aur sirf move hota hai. 

.container:hover {
  transform: scale(1.5);
  transform: translate(500px);
}

✅ Better Version

Saare transform ek hi line me combine karo. Delay kam rakho taake UI responsive lage. 

.container {
  transition: transform 0.8s ease;
}

.container:hover {
  transform: scale(1.2) translateX(120px);
}
