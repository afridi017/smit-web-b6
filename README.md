### 📚 Topics Covered

#### **1. HTML Fundamentals**

- [x] Basic Structure, Headings `h1-h6`, Paragraphs
- [x] Text Formatting: `b, i, u, mark, del, ins, sup, sub`
- [x] Lists: `ul, ol, nested lists`
- [x] Links: `a href` Absolute & Relative
- [x] Images: `img` with alt, title, width, height
- [x] Tables: `table, tr, td, th, colspan, rowspan`
- [x] Forms: `input, label, select, textarea, button, datalist`
- [x] Input Types: `text, email, password, radio, checkbox, file, date`
- [x] Multimedia: `audio, video, iframe`
- [x] Semantic Tags: `header, nav, section, article, footer, main`

#### **2. CSS Concepts**

- [x] Attribute Selectors: `^=, $=, *=, =`
- [x] Box Model, Border, Padding, Margin
- [x] Position: `static, relative, absolute, fixed`
- [x] Colors, Background, Fonts
- [x] Responsive Design Basics
